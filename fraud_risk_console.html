Model trained on 20,000 synthetic bookings (2.3% base fraud rate) with features matching the six signals above. Threshold set at 0.20 probability rather than the default 0.5 — in fraud detection a missed chargeback is usually costlier than a false alarm held for manual review, so the model is tuned to favor recall. This console's slider math replicates the roadmap's weighted-scoring logic for teaching/demo purposes; the actual trained model (see fraud_model.py) is a gradient-boosted classifier, not a hand-coded rule engine.
